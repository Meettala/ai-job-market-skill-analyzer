# AI Job Market Skill Analyzer

Extracts and ranks the skills that actually show up in AI/ML job postings,
then compares them against a candidate's own skill list to produce a gap
report — built to answer "what should I actually be learning right now?"
with data instead of guesswork.

## Why it's safe to demo publicly

Runs entirely on **synthetic sample postings** (`data/sample_postings.json`,
generated by `data/generate_sample_postings.py`) rather than scraped data —
see `docs/security/safety-rules.md` for why. Swap in a permitted real
dataset later and everything downstream works unchanged.

## How it works

1. `src/analyzer/extractor.py` — pulls skills out of posting text. Works
   with **zero API key** (rule-based keyword taxonomy). Optionally layers
   in LLM-assisted extraction if `OPENAI_API_KEY` or `ANTHROPIC_API_KEY`
   is set.
2. `src/analyzer/db.py` — stores postings + extracted skills in SQLite.
3. `src/analyzer/report.py` — pandas/SQL aggregation: skill frequency,
   co-occurrence, and the candidate gap report.
4. `src/analyzer/pipeline.py` — runs the whole thing end-to-end and
   exports `exports/analysis.json` (consumed by the static dashboard on
   the portfolio site).
5. `streamlit_app/app.py` — interactive local dashboard.

## Run it

```bash
pip install -r requirements.txt
python -m src.analyzer.pipeline     # run the pipeline, produce exports/analysis.json
streamlit run streamlit_app/app.py  # interactive dashboard
```

## Tests

```bash
pip install pytest
python -m pytest tests/ -q
```
